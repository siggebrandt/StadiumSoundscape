## About The Project

StadiumSoundscape is an interactive web application that explores the acoustic environments of Ullevi Arena and Eleda Stadion. By combining 3D visualization, geospatial mapping, and ambient audio, the project allows users to experience and compare how sound behaves in different stadium environments.

The application was developed to create an engaging way of exploring stadium acoustics through immersive visual and auditory interaction.

## Live Demo

https://stadiumsoundscape.vercel.app

## Features

- Interactive 3D stadium visualization
- Stadium location mapping with Mapbox
- Immersive soundscape exploration
- Comparison between Ullevi Arena and Eleda Stadion
- Responsive web interface
- Real-time camera navigation and interaction

## Getting Started

### Prerequisites

- Node.js 20+
- npm

### Installation

```bash
git clone https://github.com/siggebrandt/StadiumSoundscape.git
cd StadiumSoundscape
npm install
```

### Run Locally

```bash
npm run dev
```

### Build

```bash
npm run build
```

## Deployment

The application is deployed with Vercel.

```bash
vercel --prod
```
